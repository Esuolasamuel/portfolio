# Color System — preciousegwuenu.com  ---  ## THEME DECLARATION  **Mode:** Dark (permanent — no light mode toggle) **Base:** Near-black `#0a0a0a` **Accent:** Chartreuse/Lime `#e8ff47` **Text:** Pure white `#ffffff` + alpha variants  ---  ## COLOR ROLES  | Role | Token | Value | Usage | |------|-------|-------|-------| | Page Background | `--color-bg-primary` | `#0a0a0a` | `<body>` background | | Section Background | `--color-bg-secondary` | `#111111` | Alternate section bg | | Card Background | `--color-bg-card` | `#1a1a1a` | Project cards, service cards | | Primary Text | `--color-text-primary` | `#ffffff` | All headings, body copy | | Secondary Text | `--color-text-secondary` | `rgba(255,255,255,0.6)` | Captions, subtitles, links | | Muted Text | `--color-text-muted` | `rgba(255,255,255,0.4)` | Placeholder text, disabled | | Primary Accent | `--color-accent-primary` | `#e8ff47` | CTAs, highlights, number labels | | Accent on Dark | `--color-text-inverse` | `#0a0a0a` | Text sitting on `#e8ff47` bg | | Border | `--color-border-default` | `#222222` | Card borders, dividers | | Subtle Border | `--color-border-subtle` | `rgba(255,255,255,0.1)` | Hairline dividers |  ---  ## ACCENT COLOR USAGE RULES  The chartreuse/lime `#e8ff47` accent is used SPARINGLY and INTENTIONALLY:  ``` ✓ CORRECT accent usage:   - Service card number labels (01, 02, 03, 04)   - CTA button backgrounds (primary CTA)   - Hover state on links   - "Watch Video" label in content grid   - Accent glow on focused interactive elements   - Preloader percentage counter  ✗ INCORRECT accent usage:   - Section backgrounds   - Body text color   - Border color on all elements   - Large filled areas   - Navigation background ```  ---  ## BACKGROUND LAYERING SYSTEM  The site uses a three-layer background system:  ``` Layer 3 (top):    Content (text, components)          z-index: 10 Layer 2 (mid):    Background images with overlays     z-index: 0 Layer 1 (base):   Page background #0a0a0a             z-index: -1 ```  ### Background Image Sections Two sections use full-bleed background images with dark overlay:  **Hero Section** — Image overlaid at ~20% opacity behind content **CTA Section** — Textured background image with heavy dark overlay (60-70%)  Both use `background-size: cover`, `background-position: center`.  ---  ## ALPHA TRANSPARENCY SYSTEM  Alpha whites are used for hierarchy differentiation without introducing new colors:  ```css rgba(255,255,255,1.0)   → Primary text, headings rgba(255,255,255,0.8)   → Strong secondary labels rgba(255,255,255,0.6)   → Secondary text, captions rgba(255,255,255,0.4)   → Muted, tertiary content rgba(255,255,255,0.2)   → Interactive hover bg rgba(255,255,255,0.1)   → Subtle borders, dividers ```  ---  ## COLOR INTERACTION STATES  | Element | Default | Hover | Active | |---------|---------|-------|--------| | Nav link | `rgba(255,255,255,0.6)` | `#ffffff` | `#ffffff` | | CTA button | `#e8ff47` | `#f0ff7a` | `#c8e000` | | Project link | `rgba(255,255,255,0.6)` | `#ffffff` | — | | Stack tag | `#1a1a1a` bg + `rgba(255,255,255,0.6)` text | `#222222` bg | — | | Footer link | `rgba(255,255,255,0.6)` | `#ffffff` | — |  ---  ## PROHIBITED COLOR BEHAVIORS  ``` ✗ No purple gradients ✗ No blue tones (unless in a screenshot thumbnail) ✗ No light mode colors on this site ✗ No semi-transparent accent (#e8ff47 at partial opacity as primary bg) ✗ No additional accent colors beyond the chartreuse/lime ✗ No white backgrounds ✗ No gray midtones (use alpha whites on dark bg instead) ```
